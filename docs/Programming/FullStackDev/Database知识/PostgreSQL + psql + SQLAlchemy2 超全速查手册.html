PostgreSQL + psql + SQLAlchemy2 超全速查手册

下面给你一份尽可能全面的整理，分成两大部分：

  1. psql 命令行操作指南
  2. SQLAlchemy 2（含 Core / ORM）常用数据库操作命令清单

我会尽量按查阅手册的形式来写，方便你后续收藏、检索和复制使用。

一、psql 命令行操作指南

psql 是 PostgreSQL 官方提供的命令行客户端。

1. 连接数据库​

1.1 基本连接​

psql -U 用户名 -d 数据库名

例如：

psql -U postgres -d mydb

1.2 指定主机和端口​

psql -h 主机 -p 端口 -U 用户名 -d 数据库名

例如：

psql -h 127.0.0.1 -p 5432 -U postgres -d mydb

1.3 使用 URI 连接​

psql postgresql://用户名:密码@主机:端口/数据库名

例如：

psql postgresql://postgres:secret@localhost:5432/mydb

1.4 通过环境变量连接​

常见环境变量：

export PGHOST=localhost
export PGPORT=5432
export PGUSER=postgres
export PGPASSWORD=secret
export PGDATABASE=mydb
psql

1.5 连接后查看当前信息​

SELECT current_user;
SELECT current_database();
SELECT version();

2. psql 元命令（反斜杠命令）​

注意：这些不是 SQL，而是 psql 自己的命令，结尾不加分号。

3. 帮助与基础信息​

3.1 查看 psql 帮助​

\?

3.2 查看 SQL 语法帮助​

\h

查看某个具体命令帮助：

\h SELECT
\h CREATE TABLE
\h ALTER TABLE

3.3 查看当前连接信息​

\conninfo

3.4 显示当前设置​

\set

查看某个变量：

\echo :DBNAME
\echo :USER
\echo :HOST
\echo :PORT

4. 数据库相关操作​

4.1 列出数据库​

\l

或：

\list

4.2 切换数据库​

\c 数据库名

例如：

\c mydb

指定用户连接：

\c mydb postgres

4.3 创建数据库​

CREATE DATABASE mydb;

指定所有者、编码等：

CREATE DATABASE mydb
    OWNER = myuser
    ENCODING = 'UTF8'
    TEMPLATE template0;

4.4 删除数据库​

DROP DATABASE mydb;

如果数据库有连接占用，可能需要先断开会话。

5. Schema 相关操作​

5.1 列出 schema​

\dn

5.2 创建 schema​

CREATE SCHEMA myschema;

指定所有者：

CREATE SCHEMA myschema AUTHORIZATION myuser;

5.3 删除 schema​

DROP SCHEMA myschema;
DROP SCHEMA myschema CASCADE;

5.4 查看当前搜索路径​

SHOW search_path;

5.5 设置搜索路径​

SET search_path TO myschema, public;

6. 表相关操作​

6.1 列出表​

当前 schema 下：

\dt

所有 schema：

\dt *.*

指定 schema：

\dt myschema.*

6.2 列出视图、序列、索引等​

\dv      -- 视图
\dm      -- 物化视图
\ds      -- 序列
\di      -- 索引
\df      -- 函数
\du      -- 角色/用户

6.3 查看表结构​

\d 表名

例如：

\d users

更详细：

\d+ users

6.4 查看 schema 下对象​

\d myschema.*

6.5 创建表​

CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(255),
    created_at TIMESTAMP NOT NULL DEFAULT now()
);

6.6 删除表​

DROP TABLE users;
DROP TABLE users CASCADE;
DROP TABLE IF EXISTS users;

6.7 重命名表​

ALTER TABLE users RENAME TO app_users;

6.8 移动表到其他 schema​

ALTER TABLE users SET SCHEMA myschema;

7. 列相关操作​

7.1 添加列​

ALTER TABLE users ADD COLUMN age INT;

带默认值：

ALTER TABLE users ADD COLUMN is_active BOOLEAN NOT NULL DEFAULT true;

7.2 删除列​

ALTER TABLE users DROP COLUMN age;
ALTER TABLE users DROP COLUMN IF EXISTS age;

7.3 重命名列​

ALTER TABLE users RENAME COLUMN username TO login_name;

7.4 修改列类型​

ALTER TABLE users ALTER COLUMN age TYPE BIGINT;

带转换：

ALTER TABLE users ALTER COLUMN age TYPE BIGINT USING age::BIGINT;

7.5 设置/删除默认值​

ALTER TABLE users ALTER COLUMN is_active SET DEFAULT true;
ALTER TABLE users ALTER COLUMN is_active DROP DEFAULT;

7.6 设置/取消 NOT NULL​

ALTER TABLE users ALTER COLUMN email SET NOT NULL;
ALTER TABLE users ALTER COLUMN email DROP NOT NULL;

8. 约束相关操作​

8.1 添加主键​

ALTER TABLE users ADD PRIMARY KEY (id);

8.2 添加唯一约束​

ALTER TABLE users ADD CONSTRAINT uq_users_email UNIQUE (email);

8.3 添加检查约束​

ALTER TABLE users ADD CONSTRAINT chk_users_age CHECK (age >= 0);

8.4 添加外键​

ALTER TABLE orders
ADD CONSTRAINT fk_orders_user_id
FOREIGN KEY (user_id) REFERENCES users(id);

带级联：

ALTER TABLE orders
ADD CONSTRAINT fk_orders_user_id
FOREIGN KEY (user_id) REFERENCES users(id)
ON DELETE CASCADE
ON UPDATE CASCADE;

8.5 删除约束​

ALTER TABLE users DROP CONSTRAINT uq_users_email;

9. 索引操作​

9.1 查看索引​

\di
\di users*

9.2 创建索引​

CREATE INDEX idx_users_email ON users(email);

9.3 创建唯一索引​

CREATE UNIQUE INDEX idx_users_username ON users(username);

9.4 多列索引​

CREATE INDEX idx_orders_user_status ON orders(user_id, status);

9.5 部分索引​

CREATE INDEX idx_users_active ON users(id) WHERE is_active = true;

9.6 表达式索引​

CREATE INDEX idx_users_lower_email ON users(LOWER(email));

9.7 并发创建索引​

CREATE INDEX CONCURRENTLY idx_users_email ON users(email);

注意：不能在事务块中运行。

9.8 删除索引​

DROP INDEX idx_users_email;
DROP INDEX CONCURRENTLY idx_users_email;

10. 数据查询​

10.1 基本查询​

SELECT * FROM users;
SELECT id, username FROM users;

10.2 条件查询​

SELECT * FROM users WHERE id = 1;
SELECT * FROM users WHERE age >= 18;
SELECT * FROM users WHERE email IS NOT NULL;

10.3 排序​

SELECT * FROM users ORDER BY created_at DESC;
SELECT * FROM users ORDER BY age ASC, id DESC;

10.4 分页​

SELECT * FROM users LIMIT 10;
SELECT * FROM users OFFSET 20;
SELECT * FROM users LIMIT 10 OFFSET 20;

10.5 去重​

SELECT DISTINCT username FROM users;

10.6 聚合查询​

SELECT COUNT(*) FROM users;
SELECT AVG(age) FROM users;
SELECT MIN(age), MAX(age) FROM users;

10.7 分组​

SELECT status, COUNT(*)
FROM orders
GROUP BY status;

带筛选：

SELECT status, COUNT(*)
FROM orders
GROUP BY status
HAVING COUNT(*) > 10;

10.8 连接查询​

INNER JOIN​

SELECT o.id, u.username
FROM orders o
JOIN users u ON o.user_id = u.id;

LEFT JOIN​

SELECT u.id, u.username, o.id AS order_id
FROM users u
LEFT JOIN orders o ON o.user_id = u.id;

RIGHT JOIN​

SELECT *
FROM users u
RIGHT JOIN orders o ON o.user_id = u.id;

FULL JOIN​

SELECT *
FROM users u
FULL JOIN orders o ON o.user_id = u.id;

10.9 子查询​

SELECT *
FROM users
WHERE id IN (
    SELECT user_id FROM orders WHERE status = 'paid'
);

10.10 EXISTS​

SELECT *
FROM users u
WHERE EXISTS (
    SELECT 1 FROM orders o WHERE o.user_id = u.id
);

10.11 CASE​

SELECT
    id,
    username,
    CASE
        WHEN age < 18 THEN 'minor'
        WHEN age < 60 THEN 'adult'
        ELSE 'senior'
    END AS age_group
FROM users;

10.12 Common Table Expression（CTE）​

WITH active_users AS (
    SELECT * FROM users WHERE is_active = true
)
SELECT * FROM active_users;

递归 CTE：

WITH RECURSIVE t(n) AS (
    VALUES (1)
    UNION ALL
    SELECT n + 1 FROM t WHERE n < 10
)
SELECT * FROM t;

10.13 窗口函数​

SELECT
    id,
    user_id,
    amount,
    ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY created_at DESC) AS rn
FROM orders;

11. 数据写入与修改​

11.1 插入数据​

INSERT INTO users (username, email)
VALUES ('alice', 'alice@example.com');

插入多行：

INSERT INTO users (username, email)
VALUES
    ('alice', 'alice@example.com'),
    ('bob', 'bob@example.com');

11.2 返回插入结果​

INSERT INTO users (username, email)
VALUES ('alice', 'alice@example.com')
RETURNING id, username;

11.3 更新数据​

UPDATE users
SET email = 'new@example.com'
WHERE id = 1;

更新多列：

UPDATE users
SET email = 'new@example.com',
    updated_at = now()
WHERE id = 1;

11.4 删除数据​

DELETE FROM users WHERE id = 1;

返回删除的数据：

DELETE FROM users
WHERE id = 1
RETURNING *;

11.5 UPSERT​

INSERT INTO users (username, email)
VALUES ('alice', 'alice@example.com')
ON CONFLICT (username)
DO UPDATE SET email = EXCLUDED.email;

忽略冲突：

INSERT INTO users (username, email)
VALUES ('alice', 'alice@example.com')
ON CONFLICT (username)
DO NOTHING;

12. 事务操作​

12.1 开启事务​

BEGIN;

12.2 提交事务​

COMMIT;

12.3 回滚事务​

ROLLBACK;

12.4 保存点​

SAVEPOINT sp1;
ROLLBACK TO SAVEPOINT sp1;
RELEASE SAVEPOINT sp1;

12.5 查看事务隔离级别​

12.6 设置事务隔离级别​

SET TRANSACTION ISOLATION LEVEL READ COMMITTED;

二、SQLAlchemy 2 数据库操作指南

下面以 SQLAlchemy 2.x 风格 为主，覆盖：

  • Engine
  • Connection
  • Transaction
  • Core
  • ORM
  • Session
  • 查询、增删改查
  • 关系、加载策略
  • PostgreSQL 常用扩展写法
  • 异步版基础

1. 安装​

PostgreSQL 驱动​

常见：

pip install sqlalchemy psycopg[binary]

或者：

pip install sqlalchemy psycopg2-binary

如果用异步：

pip install sqlalchemy asyncpg

2. 创建 Engine​

2.1 同步 Engine​

from sqlalchemy import create_engine

engine = create_engine(
    "postgresql+psycopg://postgres:secret@localhost:5432/mydb",
    echo=True,
)

2.2 常见参数​

engine = create_engine(
    "postgresql+psycopg://postgres:secret@localhost:5432/mydb",
    echo=True,              # 打印 SQL
    future=True,            # 2.x 中通常可省略
    pool_size=10,
    max_overflow=20,
    pool_timeout=30,
    pool_recycle=1800,
    pool_pre_ping=True,
)

3. 连接与执行 SQL​

3.1 获取连接​

from sqlalchemy import text

with engine.connect() as conn:
    result = conn.execute(text("SELECT 1"))
    print(result.scalar())

3.2 执行原生 SQL​

with engine.connect() as conn:
    result = conn.execute(
        text("SELECT * FROM users WHERE id = :id"),
        {"id": 1}
    )
    rows = result.all()
    print(rows)

3.3 提交事务​

engine.connect() 默认需要手动提交 DML：

with engine.connect() as conn:
    conn.execute(text("INSERT INTO users (username) VALUES (:u)"), {"u": "alice"})
    conn.commit()

3.4 自动事务块​

with engine.begin() as conn:
    conn.execute(text("INSERT INTO users (username) VALUES (:u)"), {"u": "alice"})

begin() 成功自动提交，异常自动回滚。

4. Metadata 与表定义（Core）​

5. 定义表​

from sqlalchemy import (
    MetaData, Table, Column, Integer, BigInteger, String,
    Boolean, DateTime, ForeignKey, Text, Numeric
)
from sqlalchemy.sql import func

metadata = MetaData()

users = Table(
    "users",
    metadata,
    Column("id", BigInteger, primary_key=True),
    Column("username", String(50), nullable=False, unique=True, index=True),
    Column("email", String(255)),
    Column("is_active", Boolean, nullable=False, server_default="true"),
    Column("created_at", DateTime, nullable=False, server_default=func.now()),
)

orders = Table(
    "orders",
    metadata,
    Column("id", BigInteger, primary_key=True),
    Column("user_id", ForeignKey("users.id", ondelete="CASCADE"), nullable=False),
    Column("amount", Numeric(10, 2), nullable=False),
    Column("status", String(20), nullable=False),
)

6. 创建/删除表​

metadata.create_all(engine)
metadata.drop_all(engine)

只创建部分表：

metadata.create_all(engine, tables=[users])

7. 插入数据（Core）​

7.1 单条插入​

from sqlalchemy import insert

stmt = insert(users).values(username="alice", email="alice@example.com")

with engine.begin() as conn:
    result = conn.execute(stmt)

7.2 多条插入​

stmt = insert(users)

data = [
    {"username": "alice", "email": "alice@example.com"},
    {"username": "bob", "email": "bob@example.com"},
]

with engine.begin() as conn:
    conn.execute(stmt, data)

7.3 RETURNING​

stmt = (
    insert(users)
    .values(username="alice", email="alice@example.com")
    .returning(users.c.id, users.c.username)
)

with engine.begin() as conn:
    row = conn.execute(stmt).first()
    print(row)

8. 查询数据（Core）​

8.1 基本查询​

from sqlalchemy import select

stmt = select(users)

with engine.connect() as conn:
    rows = conn.execute(stmt).all()
    print(rows)

8.2 选择部分列​

stmt = select(users.c.id, users.c.username)

8.3 条件过滤​

stmt = select(users).where(users.c.id == 1)
stmt = select(users).where(users.c.age >= 18)
stmt = select(users).where(users.c.email.is_not(None))

8.4 多条件​

from sqlalchemy import and_, or_

stmt = select(users).where(
    and_(
        users.c.is_active.is_(True),
        users.c.email.is_not(None),
    )
)

stmt = select(users).where(
    or_(
        users.c.username == "alice",
        users.c.username == "bob",
    )
)

8.5 排序与分页​

stmt = select(users).order_by(users.c.created_at.desc())
stmt = select(users).limit(10).offset(20)

8.6 去重​

stmt = select(users.c.username).distinct()

8.7 聚合​

from sqlalchemy import func

stmt = select(func.count()).select_from(users)
stmt = select(func.avg(users.c.age))
stmt = select(func.min(users.c.age), func.max(users.c.age))

8.8 分组​

stmt = (
    select(orders.c.status, func.count())
    .group_by(orders.c.status)
    .having(func.count() > 10)
)

8.9 JOIN​

stmt = (
    select(orders.c.id, users.c.username)
    .select_from(orders.join(users, orders.c.user_id == users.c.id))
)

左连接：

stmt = (
    select(users.c.id, users.c.username, orders.c.id.label("order_id"))
    .select_from(users.outerjoin(orders, users.c.id == orders.c.user_id))
)

8.10 子查询​

subq = select(orders.c.user_id).where(orders.c.status == "paid")

stmt = select(users).where(users.c.id.in_(subq))

8.11 EXISTS​

from sqlalchemy import exists

stmt = select(users).where(
    exists(
        select(1).where(orders.c.user_id == users.c.id)
    )
)

8.12 CTE​

active_users = select(users).where(users.c.is_active.is_(True)).cte("active_users")
stmt = select(active_users)

8.13 窗口函数​

stmt = select(
    orders.c.id,
    orders.c.user_id,
    orders.c.amount,
    func.row_number().over(
        partition_by=orders.c.user_id,
        order_by=orders.c.id.desc()
    ).label("rn")
)

11. PostgreSQL UPSERT（Core）​

from sqlalchemy.dialects.postgresql import insert

stmt = insert(users).values(
    username="alice",
    email="alice@example.com"
)

stmt = stmt.on_conflict_do_update(
    index_elements=[users.c.username],
    set_={"email": stmt.excluded.email}
)

with engine.begin() as conn:
    conn.execute(stmt)

stmt = insert(users).values(
    username="alice",
    email="alice@example.com"

from decimal import Decimal

14. 定义模型​

class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    username: Mapped[str] = mapped_column(String(50), unique=True, index=True)
    email: Mapped[Optional[str]] = mapped_column(String(255))
    is_active: Mapped[bool] = mapped_column(Boolean, default=True, server_default="true")
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())

    orders: Mapped[List["Order"]] = relationship(
        back_populates="user",
        cascade="all, delete-orphan"
    )


class Order(Base):
    __tablename__ = "orders"

    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"))
    amount: Mapped[Decimal] = mapped_column(Numeric(10, 2))
    status: Mapped[str] = mapped_column(String(20))

    user: Mapped["User"] = relationship(back_populates="orders")
